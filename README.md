# 📝 MERN Todo List Application

A full-stack Todo List application built using the **MERN Stack**.

## 🚀 Features

- Add a new task
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as Pending or Completed
- Search tasks by title
- Filter tasks (All, Pending, Completed)
- Sort tasks (Newest, Oldest)
- Task Priority (Low, Medium, High)
- Dashboard showing:
  - Total Tasks
  - Pending Tasks
  - Completed Tasks
- Responsive User Interface
- Toast Notifications

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Axios
- React Toastify
- React Icons
- CSS

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Harpreet28082006/TodoList-MERN.git
```

### Backend

```bash
cd Server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```
